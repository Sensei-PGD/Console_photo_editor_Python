# Console_photo_editor_Python

## 🖼 Консольный фоторедактор

**Простой фоторедактор для командной строки на Python с 16 фильтрами обработки изображений.**

---

## 📖 О программе

**Консольный фоторедактор** — это приложение на Python для обработки изображений прямо из терминала. Вы указываете путь к картинке, выбираете фильтр из меню, и программа сохраняет обработанное изображение в указанное место.

Не требует графического интерфейса — работает в **любом терминале**, где есть Python.

---

## 📋 Требования

- **Python 3.8+**
- **Pillow** (библиотека работы с изображениями)

Установка:

```bash
pip install Pillow
```

---

## ⚙️ Установка и запуск
1. Скопируйте файлы проекта в отдельную папку:

```text
photoeditor/
├── main.py         ← основной файл
└── filters.py      ← файл с фильтрами
```

2. Установите зависимость:

```bash
pip install Pillow
```

3. Запустите программу:

```bash
python main.py
```

---

## 🎮 Как пользоваться

1. **Введите путь к изображению.**
   - Формат: `G:/folder/sample.jpeg`
   - Поддерживаются: `.jpg`, `.jpeg`, `.png`, `.bmp`, `.gif`, `.webp`

2. **Выберите фильтр** — введите номер из меню (1–16) или `0` для выхода.

3. **Прочитайте описание** фильтра.

4. **Подтвердите применение** — введите `Да` или `Нет`.

5. **Укажите путь сохранения** — например, `G:/folder/result.png`.

6. **Готово!** Изображение сохранено.

7. **Повторить или выйти** — введите `Да` для новой обработки или `Нет` для выхода.

## 🗂 Структура проекта

```text
photoeditor/
├── main.py        ← главный файл, точка входа
├── filters.py     ← все 16 классов фильтров
└── README.md      ← этот файл
```

### Архитектура
- `main.py` — взаимодействие с пользователем, меню, чтение пути, сохранение.

- `filters.py` — классы фильтров. У каждого:

  - `name` — название фильтра.

  - `description` — описание.

  - `apply(image)` — метод, применяющий фильтр и возвращающий новое изображение.

---

## 📝 Известные особенности
- Путь к изображению — указывайте **абсолютный путь**, а не просто имя файла.

- **Сохранение** — если файл уже существует, он **будет перезаписан**.

- **Формат RGB** — изображение конвертируется в RGB при открытии.

- **Регистр ответов** — `Да` / `Нет` — программа понимает **любой регистр** (`да`, `ДА`, `Да`).
